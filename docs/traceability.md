# Medical Software Traceability Matrix (IEC 62304 / ISO 13485 Principles)

In regulated medical device and medical software development, **traceability** ensures that every clinical requirement (User Need / Input) maps directly to concrete implementation artifacts (Output) and is rigorously verified through automated testing (Verification).
